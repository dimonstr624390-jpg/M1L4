###Pokemon Telegram Bot

Telegram-бот, в котором каждый игрок может завести себе собственного покемона, кормить его и сражаться с покемонами других участников чата. Данные о покемонах (имя и картинка) подгружаются из открытого PokeAPI.

##Возможности
Создание случайного покемона одним из трёх классов: Pokemon, Wizard или Fighter
Система редкости с разной вероятностью выпадения и бонусами
Кормление покемона для восстановления и увеличения здоровья
PvP-сражения между игроками (команда отправляется ответом на сообщение соперника)
Загрузка названия и изображения покемона из PokeAPI

##Команды бота
#Команда	Описание
/go	Создать своего покемона (только один на игрока)
/info	Показать информацию о своём покемоне: имя, редкость, здоровье, силу, картинку
/feed	Покормить покемона (+здоровье). Кормить можно не чаще, чем раз в 20 часов
/attack	Атаковать покемона другого игрока. Отправляется ответом на сообщение соперника

##Классы покемонов
#Класс	Особенности
Pokemon	Базовый класс, кормление даёт +10 HP
Wizard	Кормление даёт +15 HP. При получении атаки может применить щит и избежать урона
Fighter	Кормление даёт +15 HP. При атаке получает случайный бонус к силе (супер-атака)

##Редкость
#Редкость	Шанс	Множитель бонуса
Обычный	70%	x1
Редкий	20%	x2
Эпический	9%	x5
Легендарный	1%	x10 + супербонус (100 очков)

Начальные характеристики случайны: здоровье — от 200 до 400, сила — от 30 до 60.

##Примеры использования
Создание покемона — /go
Команда /go
Информация о покемоне — /info
Команда /info
Кормление — /feed
Команда /feed
Сражение — /attack
Команда /attack

##Технологии

pyTelegramBotAPI (telebot)
requests

###Примечания
Данные игроков хранятся в памяти, поэтому после перезапуска бота все покемоны сбрасываются.
Проект создан как вилка учебного репозитория KodlandLVL3/M1L4.
